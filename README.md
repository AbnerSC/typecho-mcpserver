# typecho mcpserver

> 将Typecho接口通过MCP Server 暴露出来，用于提供给`AI Agent`使用

1. Typecho 源码仓库 `https://github.com/typecho/typecho.git`
2. Typecho 插件开发说明文档 `https://docs.typecho.org/develop/plugin/`

## 接口清单
- 撰写文章（新文章默认保存草稿，不发布文章）
- 创建页面
- 编辑文章
- 管理分类
- 管理标签
